## `> ABOUT_ME.exe`

Olá! Eu sou **Douglas Galdino**, estudante do **3º ano do Ensino Médio Técnico em Desenvolvimento de Sistemas na Etec Sebrae**, com conclusão prevista para dezembro de 2026.

Meu foco é o **desenvolvimento Front-End**. Gosto de criar interfaces modernas, responsivas e funcionais, combinando programação com conceitos de **UI/UX** para proporcionar experiências melhores aos usuários.

Durante minha formação, venho desenvolvendo projetos acadêmicos e pessoais que me permitem colocar meus conhecimentos em prática, enfrentar novos desafios e explorar diferentes soluções.
